## Tools

- [Finnik.nl](https://finnik.nl) — BPM opzoeken per kenteken (NL)
- [VWE BPM-exportcalculator](https://www.vwe.nl/autobedrijven/bpm-calculator-export) — rest-BPM berekenen bij export (NL)
- [ImportEspana BOE-waarde](https://importespana.com/valoracion-boe) — fiscale waarde opzoeken (ES)
- [Dieselogasolina calculator](https://www.dieselogasolina.com/calcular-impuesto-matriculacion-coche-moto-hacienda.html) — impuesto de matriculación berekenen (ES)
- [CAR-PASS](https://www.car-pass.be) — kilometerhistorie controleren (BE)

Geen fiscaal/juridisch advies. Regels en tarieven wijzigen. Check altijd de Belastingdienst, RDW, DIV, DGT en Agencia Tributaria.
